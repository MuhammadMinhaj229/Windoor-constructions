## 2026-07-02 - Remove Invisible Backdrop Filters on Opaque Elements
**Learning:** Fixed elements (header, mobile sticky bar) were given expensive Tailwind `backdrop-blur-*` utilities alongside fully opaque `bg-white` backgrounds. This creates a severe performance anti-pattern on mobile: the browser continuously calculates heavy blur operations on every scroll frame for an effect that is 100% hidden by the solid background.
**Action:** Always ensure elements with `backdrop-filter` have semi-transparent backgrounds (e.g., `bg-white/80`). If an opaque background is desired, the `backdrop-blur` utility must be removed to avoid destroying scroll FPS.

## 2026-07-03 - Defer Off-screen Section Layout with content-visibility
**Learning:** For long landing pages with many complex sections and DOM elements (like product catalogues, galleries, FAQs), rendering everything synchronously blocks the main thread and severely degrades initial First Contentful Paint (FCP) and Largest Contentful Paint (LCP) performance. Using \`content-visibility: auto\` with \`contain-intrinsic-block-size\` prevents the browser from doing layout and rendering work for below-the-fold sections until they are scrolled into the viewport.
**Action:** Apply \`content-visibility: auto\` with a placeholder size (e.g., \`contain-intrinsic-block-size: 1000px\`) to all non-critical, off-screen sections (like contact, FAQs, galleries) on long pages. Avoid using \`contain-intrinsic-size\` directly to prevent horizontal overflow issues on mobile.
