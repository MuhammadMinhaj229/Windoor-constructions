## 2026-07-02 - Remove Invisible Backdrop Filters on Opaque Elements
**Learning:** Fixed elements (header, mobile sticky bar) were given expensive Tailwind `backdrop-blur-*` utilities alongside fully opaque `bg-white` backgrounds. This creates a severe performance anti-pattern on mobile: the browser continuously calculates heavy blur operations on every scroll frame for an effect that is 100% hidden by the solid background.
**Action:** Always ensure elements with `backdrop-filter` have semi-transparent backgrounds (e.g., `bg-white/80`). If an opaque background is desired, the `backdrop-blur` utility must be removed to avoid destroying scroll FPS.
## 2026-07-16 - Use content-visibility: auto for Long Landing Pages
**Learning:** For long landing pages with many sections (like image galleries, FAQs, and contact forms), rendering everything simultaneously blocks the main thread and hurts First Contentful Paint (FCP) and Largest Contentful Paint (LCP). By applying `content-visibility: auto` with a `contain-intrinsic-block-size` placeholder (e.g., `1000px`) on below-the-fold sections, the browser defers layout and rendering calculations until the user scrolls them into view, significantly improving initial page load performance. Note: Do not use `contain-intrinsic-size: 1000px` as it applies to both width and height, causing severe horizontal overflow bugs on mobile viewports (<1000px wide).
**Action:** Always apply `.content-auto-defer` to below-the-fold sections on long landing pages to optimize rendering.
