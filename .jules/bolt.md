## 2026-07-02 - Remove Invisible Backdrop Filters on Opaque Elements
**Learning:** Fixed elements (header, mobile sticky bar) were given expensive Tailwind `backdrop-blur-*` utilities alongside fully opaque `bg-white` backgrounds. This creates a severe performance anti-pattern on mobile: the browser continuously calculates heavy blur operations on every scroll frame for an effect that is 100% hidden by the solid background.
**Action:** Always ensure elements with `backdrop-filter` have semi-transparent backgrounds (e.g., `bg-white/80`). If an opaque background is desired, the `backdrop-blur` utility must be removed to avoid destroying scroll FPS.
## 2024-07-10 - Defer Layout for Below-the-Fold Sections
**Learning:** For long landing pages like `index.html` with many sections containing images or complex content, standard rendering blocks initial First Contentful Paint (FCP) while it calculates layout for the whole page. Using `content-visibility: auto` combined with a `contain-intrinsic-size` placeholder (e.g., `1000px`) on below-the-fold or off-screen sections defers their layout and rendering until they approach the viewport. This significantly improves FCP and Largest Contentful Paint (LCP) performance on long pages.
**Action:** When working with vanilla HTML landing pages containing many distinct sections, apply a `.content-hidden { content-visibility: auto; contain-intrinsic-size: 1000px; }` class to sections outside the initial viewport to defer expensive rendering operations. Note that this causes blank spaces in full-page screenshots since elements only render on natural scroll.
