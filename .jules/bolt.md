## 2026-07-02 - Remove Invisible Backdrop Filters on Opaque Elements
**Learning:** Fixed elements (header, mobile sticky bar) were given expensive Tailwind `backdrop-blur-*` utilities alongside fully opaque `bg-white` backgrounds. This creates a severe performance anti-pattern on mobile: the browser continuously calculates heavy blur operations on every scroll frame for an effect that is 100% hidden by the solid background.
**Action:** Always ensure elements with `backdrop-filter` have semi-transparent backgrounds (e.g., `bg-white/80`). If an opaque background is desired, the `backdrop-blur` utility must be removed to avoid destroying scroll FPS.

## 2026-07-13 - Defer Rendering of Below-the-Fold Content
**Learning:** For long vanilla HTML landing pages, the initial layout and paint calculations can block the main thread. Using `content-visibility: auto` along with `contain-intrinsic-block-size` on below-the-fold sections defers rendering and layout, drastically improving initial First Contentful Paint (FCP) and Largest Contentful Paint (LCP) performance. Note that `contain-intrinsic-size: 1000px` must be avoided to prevent severe horizontal overflow bugs on mobile viewports (<1000px wide), which is why `contain-intrinsic-block-size` is used specifically for the vertical dimension.
**Action:** Always apply `.defer-render { content-visibility: auto; contain-intrinsic-block-size: [estimated-height]; }` to off-screen or below-the-fold container elements (e.g., `<section>`) in long scrolling pages to optimize rendering.
