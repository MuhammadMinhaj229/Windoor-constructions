## 2026-07-02 - Remove Invisible Backdrop Filters on Opaque Elements
**Learning:** Fixed elements (header, mobile sticky bar) were given expensive Tailwind `backdrop-blur-*` utilities alongside fully opaque `bg-white` backgrounds. This creates a severe performance anti-pattern on mobile: the browser continuously calculates heavy blur operations on every scroll frame for an effect that is 100% hidden by the solid background.
**Action:** Always ensure elements with `backdrop-filter` have semi-transparent backgrounds (e.g., `bg-white/80`). If an opaque background is desired, the `backdrop-blur` utility must be removed to avoid destroying scroll FPS.
## 2026-07-03 - Defer Off-screen Section Rendering
**Learning:** For long landing pages like this codebase's `index.html`, initial load performance (FCP/LCP) can be significantly delayed by the browser calculating layouts and rendering all off-screen `<section>` elements (like contact, FAQ, gallery) synchronously. Using `content-visibility: auto` paired with `contain-intrinsic-block-size` creates massive layout performance gains by deferring these sections until scrolled near viewport. Do not use `contain-intrinsic-size` as it applies a fixed width, causing mobile overflow bugs on `<1000px` viewports.
**Action:** Apply `.defer-render` (containing `content-visibility: auto; contain-intrinsic-block-size: 1000px;`) to all non-critical, below-the-fold container sections on long static HTML pages.
