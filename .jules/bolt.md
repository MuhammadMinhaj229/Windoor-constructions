## 2026-07-02 - Remove Invisible Backdrop Filters on Opaque Elements
**Learning:** Fixed elements (header, mobile sticky bar) were given expensive Tailwind `backdrop-blur-*` utilities alongside fully opaque `bg-white` backgrounds. This creates a severe performance anti-pattern on mobile: the browser continuously calculates heavy blur operations on every scroll frame for an effect that is 100% hidden by the solid background.
**Action:** Always ensure elements with `backdrop-filter` have semi-transparent backgrounds (e.g., `bg-white/80`). If an opaque background is desired, the `backdrop-blur` utility must be removed to avoid destroying scroll FPS.
## 2026-07-03 - Defer Rendering for Off-Screen Sections
**Learning:** For long landing pages, using `content-visibility: auto` with a `contain-intrinsic-block-size` placeholder (e.g., `1000px`) on below-the-fold or off-screen sections defers layout and rendering calculations. This significantly improves initial First Contentful Paint (FCP) and Largest Contentful Paint (LCP) performance. However, avoid using `contain-intrinsic-size` as it applies to both width and height, causing severe horizontal overflow bugs on mobile viewports (<1000px wide).
**Action:** Always apply `content-visibility: auto` and `contain-intrinsic-block-size` to long list of off-screen sections to optimize initial rendering speed.
