## 2026-07-02 - Remove Invisible Backdrop Filters on Opaque Elements
**Learning:** Fixed elements (header, mobile sticky bar) were given expensive Tailwind `backdrop-blur-*` utilities alongside fully opaque `bg-white` backgrounds. This creates a severe performance anti-pattern on mobile: the browser continuously calculates heavy blur operations on every scroll frame for an effect that is 100% hidden by the solid background.
**Action:** Always ensure elements with `backdrop-filter` have semi-transparent backgrounds (e.g., `bg-white/80`). If an opaque background is desired, the `backdrop-blur` utility must be removed to avoid destroying scroll FPS.
## 2026-07-06 - Defer Off-Screen Layouts on Long Pages
**Learning:** In long landing pages with many heavy sections (like full product catalogues and image galleries), forcing the browser to layout the entire page at once during FCP/LCP blocks the main thread. Implementing `content-visibility: auto` with a `contain-intrinsic-size` placeholder defers layout for off-screen elements until they approach the viewport, significantly improving initial paint times.
**Action:** Always apply `content-visibility: auto; contain-intrinsic-size: 1000px;` to deep below-the-fold `<section>` elements in long-scrolling static sites to prioritize rendering critical above-the-fold content.
