## 2026-07-02 - Remove Invisible Backdrop Filters on Opaque Elements
**Learning:** Fixed elements (header, mobile sticky bar) were given expensive Tailwind `backdrop-blur-*` utilities alongside fully opaque `bg-white` backgrounds. This creates a severe performance anti-pattern on mobile: the browser continuously calculates heavy blur operations on every scroll frame for an effect that is 100% hidden by the solid background.
**Action:** Always ensure elements with `backdrop-filter` have semi-transparent backgrounds (e.g., `bg-white/80`). If an opaque background is desired, the `backdrop-blur` utility must be removed to avoid destroying scroll FPS.
## 2026-07-02 - Content-Visibility Optimization for Long Landing Pages
**Learning:** For long landing pages like this codebase's monolithic `index.html`, deferred rendering is critical for LCP/FCP. Using `content-visibility: auto` defers rendering of off-screen elements. However, simply pairing it with `contain-intrinsic-size: 1000px` applies to both width and height, causing severe horizontal overflow bugs on mobile viewports (<1000px wide).
**Action:** Use `contain-intrinsic-block-size: 1000px` (or a similar placeholder value) to only apply the intrinsic size to the height block, keeping the layout constrained horizontally to the viewport width while still skipping rendering work.
