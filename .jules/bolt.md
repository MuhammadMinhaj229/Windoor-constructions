## 2026-07-02 - Remove Invisible Backdrop Filters on Opaque Elements
**Learning:** Fixed elements (header, mobile sticky bar) were given expensive Tailwind `backdrop-blur-*` utilities alongside fully opaque `bg-white` backgrounds. This creates a severe performance anti-pattern on mobile: the browser continuously calculates heavy blur operations on every scroll frame for an effect that is 100% hidden by the solid background.
**Action:** Always ensure elements with `backdrop-filter` have semi-transparent backgrounds (e.g., `bg-white/80`). If an opaque background is desired, the `backdrop-blur` utility must be removed to avoid destroying scroll FPS.

## 2026-07-03 - Avoid Premature DOM Caching and Redundant Preloads
**Learning:** Storing DOM queries like `document.getElementById` or `querySelectorAll` in global cache variables is often a micro-optimization that risks causing stale nodes and unexpected bugs. Modern browsers execute these operations in fractions of a millisecond, making the cache redundant and leading to misleading JSDOM benchmark improvements. Additionally, using `<link rel="preload">` immediately before a corresponding `<link rel="stylesheet">` provides no First Contentful Paint (FCP) benefit because modern browsers parse and fetch them simultaneously.
**Action:** Avoid global variables for DOM caching unless it's a proven bottleneck in a hot loop (e.g., thousands of iterations per frame). Use targeted `document.querySelector` (O(1)) instead of iterating over cached `querySelectorAll` (O(N)) lists to mutate singular states. Only use `<link rel="preload">` for critical assets that are discovered late in the HTML rendering process.
