# Windoor Constructions — Architectural Windows & Doors Fabrication Showcase

[![Brand](https://img.shields.io/badge/Client-Windoor_Constructions-blue?style=flat-square)](https://alif-growth.netlify.app)
**Windoor Constructions** is a digital product showroom and quotation estimator for UPVC windows, aluminum structural glazing, and architectural door fabrication.

---

## Highlights

- **Interactive Specification Showcase:** Detailed view of UPVC sliding windows, casement doors, and acoustic insulated glazing.
- **Instant Estimation Form:** Customers can enter frame dimensions and glass types to receive a ballpark quote.
- **Direct WhatsApp Quote Request:** Transmits selected measurements directly to the fabrication workshop manager.

---

## Local Setup & Deployment

```bash
git clone https://github.com/MuhammadMinhaj229/Windoor-constructions.git
cd Windoor-constructions
npx serve .
```
Deployable instantly to **Vercel**, **Netlify**, or **GitHub Pages**.
